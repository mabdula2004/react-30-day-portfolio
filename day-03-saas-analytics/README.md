# Day 03 — Lumen SaaS Analytics Landing Page

A premium, responsive React landing page for an AI-native analytics SaaS product.

## Design direction

Rather than cloning a reference, Lumen combines current SaaS patterns observed across 2026 analytics work: product-first hero composition, credible live-looking metrics, restrained dark green + acid-lime identity, editorial serif accents, modular data cards, strong social proof, and a mobile layout treated as a true adaptation.

## Features
- Conversion-focused hero with product preview
- Realistic analytics dashboard and revenue visualization
- Responsive navigation with mobile menu
- Product feature storytelling
- Customer proof and quantified outcome
- Simple pricing section and final CTA
- Desktop, tablet, and mobile breakpoints
- Hover/focus-friendly interactive elements
- Semantic page structure

## Run locally
```bash
npm install
npm run dev
```

## Stack
React · Vite · Lucide React · CSS
