# React 30-Day Portfolio Challenge

A 30-day portfolio challenge focused on building modern React interfaces, then progressively adding real JavaScript logic, React Native, Supabase, and full-stack skills.

## Structure

- **Days 1–15:** UI / design-focused React projects
- **Days 16–30:** UI + JavaScript / React logic
- Later days introduce React Native and Supabase
- Projects are responsive, reusable, and portfolio-ready
- Light and dark themes are included across the challenge

## Projects

### Day 01 — Login + Registration Portal
Path: `day-01-login-register-ui/`

A polished authentication interface featuring a responsive split-screen layout, reusable components, light/dark theme support, password visibility controls, and modern UI styling.

### Day 02 — Developer Portfolio UI
Path: `day-02-developer-portfolio/`

An editorial developer portfolio with oversized typography, selected work cards, about/skills, experience timeline, contact CTA, modular responsive CSS, and persistent light/dark themes.

More projects will be added day by day.
