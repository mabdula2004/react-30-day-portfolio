# React 30-Day Portfolio Challenge

A 30-day frontend portfolio challenge focused on building modern React interfaces, then progressively adding real JavaScript logic, React Native, and Supabase.

## Structure

- **Days 1–15:** UI / design-focused React projects
- **Days 16–30:** UI + JavaScript / React logic
- Later days also introduce React Native and Supabase
- Projects are designed to be responsive, reusable, and portfolio-ready
- Light and dark themes are included where appropriate

## Projects

### Day 01 — Login + Registration Portal
Path: `day-01-login-register-ui/`

A polished React authentication interface featuring a responsive split-screen layout, reusable components, light/dark theme support, password visibility controls, and modern UI styling.

More projects will be added day by day.
