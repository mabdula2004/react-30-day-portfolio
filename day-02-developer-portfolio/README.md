# Day 02 — Developer Portfolio UI

A medium-sized, modern developer portfolio interface built with React as part of the 30-Day Portfolio Challenge.

## Design direction

Editorial typography, warm neutral surfaces, bold accent colors, asymmetric composition, oversized hero type, tactile project cards, and a strong light/dark theme system.

## Sections

- Responsive navigation
- Hero / availability statement
- Selected projects
- About + skills
- Experience journey
- Contact CTA + footer

## UI features

- Light and dark themes with persistence
- Fully responsive desktop/tablet/mobile layout
- Reusable React components
- Accessible navigation labels
- Reduced-motion support
- Modular CSS architecture

## Stack

React • Vite • CSS • Lucide React

## Run

```bash
npm install
npm run dev
```

This project is intentionally UI-focused. Business logic and backend features are introduced later in the 30-day challenge.
